# 批量导出 / 导入 Markdown

在同一个顶栏面板里，把笔记本批量导出为 Markdown ZIP，或把 Markdown ZIP 批量导入到笔记本。

## 功能

### 导出

- 勾选一个或多个笔记本，导出为 Markdown ZIP。
- 加密笔记本自动禁用。
- 通过思源的保存对话框保存 ZIP；取消后可以点击「重新下载」。
- 可选：包含子文档、添加文档标题、添加 YAML Front Matter、资源文件去掉 ID。

### 导入

- 选择目标笔记本和可选的导入路径。
- 选择 Markdown ZIP（例如本插件导出的 ZIP）。
- 可选择跳过 ZIP 根目录。
- 通过 `/api/import/importZipMd` 上传，导入完成后自动刷新文档树。

## 使用

1. 点击顶栏下载图标。
2. 在「导出」和「导入」两个标签之间切换。
3. 导出：勾选笔记本后点击「导出」。
4. 导入：选择笔记本、目标路径和 `.zip` 文件，点击「开始导入」。

右键顶栏图标可以直接打开导出或导入标签。

## 说明

- 导入只列出非加密笔记本。
- ZIP 内可以包含 `.md` 文件和文件夹，文件夹会按文档层级导入。
- 如果 ZIP 里只有一个顶层文件夹，勾选「跳过 ZIP 根目录」可以避免多出一层文档。
