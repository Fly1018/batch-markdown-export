# 批量导出 / 导入 Markdown

把笔记本批量导出为 Markdown ZIP、把 Markdown ZIP 批量导入到笔记本，或者用快捷键一键执行预设的导出/导入。

## 功能

### 导出

- 勾选一个或多个笔记本，导出为 Markdown ZIP。
- 加密笔记本自动禁用。
- 通过思源的保存对话框保存 ZIP；取消后可以点击「重新下载」。
- 可选：包含子文档、添加文档标题、添加 YAML Front Matter、资源文件去掉 ID。

### 导入

- 选择目标笔记本和可选的导入路径。
- 选择 Markdown ZIP（例如本插件导出的 ZIP）。
- 可选择跳过 ZIP 根目录。
- 通过 `/api/import/importZipMd` 上传，导入完成后自动刷新文档树。

### 一键导出 / 导入

先在「一键」标签里配置一次：

- 默认导出笔记本
- 保存方式：**询问保存位置** 或 **直接下载**
- 默认导入文件夹（本机上的 Markdown 文件夹，需在工作区之外）
- 目标笔记本、目标路径、是否跳过文件夹根目录

配置完成后：

- `⇧⌘E` — 立即导出默认笔记本
- `⇧⌘I` — 立即导入默认文件夹

这两个命令也会出现在命令面板中，快捷键可在「设置 → 快捷键」里修改。如果配置不完整，命令会打开「一键」标签并提示补充。

## 使用

1. 点击顶栏下载图标。
2. 在「导出」「导入」「一键」三个标签之间切换。
3. 导出：勾选笔记本后点击「导出」。
4. 导入：选择笔记本、目标路径和 `.zip` 文件，点击「开始导入」。
5. 一键：填好默认值后，用快捷键执行。

右键顶栏图标可以直接打开导出/导入标签，或执行一键命令。

## 说明

- 导入只列出非加密笔记本；一键导入需要目标笔记本处于打开状态。
- 导入文件夹必须是本机文件夹，且不能位于思源工作区内部。
- 「直接下载」会保存到浏览器默认下载目录，不再弹出保存对话框。
- ZIP 内可以包含 `.md` 文件和文件夹，文件夹会按文档层级导入。
